# 🤖 Jarvis AI Assistant

### AI-Powered Voice Assistant Built with Python

## 📌 About the Project

Jarvis AI Assistant is a Python-based desktop voice assistant designed to make computer interaction easier through voice commands and artificial intelligence.

It understands user commands, responds through voice, and helps perform different tasks on the computer.

## ✨ Features

- 🎙️ Voice-based interaction
- 🧠 AI-powered Natural Language Understanding
- 😊 Mood-aware responses
- 🔊 Text-to-Speech responses
- 🌐 Google and YouTube search
- 📂 File searching
- 💻 Application launching
- ⏰ Timer and alarm functionality
- 📄 PDF generation
- 📸 Screenshot functionality
- 💬 WhatsApp interaction with confirmation
- 💤 Wake and sleep mode

## 🛠️ Technologies Used

- Python
- Groq API
- Speech Recognition
- Edge TTS
- Tkinter / CustomTkinter
- Pygame
- PyAutoGUI
- Selenium
- Requests

## 💻 Project Type

Python Desktop Application

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Jarvis-AI-Assistant.git
```

### 2. Open Project Folder

```bash
cd Jarvis-AI-Assistant
```

### 3. Install Required Libraries

```bash
pip install requests pygame SpeechRecognition edge-tts pyautogui pyperclip psutil pywhatkit fpdf openai selenium customtkinter
```

Some features may require additional system setup or browser configuration.

### 4. Configure API Key

Set your Groq API key in the `GROQ_API_KEY` environment variable before running the application.

Never share your API key publicly.

### 5. Run Jarvis

```bash
python jarvis_mood_aware_v14(3).py
```
